# Logo inbox

Small venue logos for the listing cards. Entirely optional — a venue
without a file here simply shows no logo.

## How

1. Save the venue's logo (their Facebook profile picture is usually the
   best source — open it, right-click, save).
2. Name the file with the venue's **slug**: the venue name, lowercased,
   with every run of non-letters/numbers replaced by a dash. Examples:
   - `Red Granite Bar & Grill` → `red-granite-bar-grill.png`
   - `4 Father's Pub` → `4-father-s-pub.png`
   - `Norm's` → `norm-s.png`
3. Upload it here (GitHub: **Add file → Upload files**). PNG, JPG, or
   WebP; any size — the build shrinks it to card size.
4. The logo appears next to the venue's name within the hour.

To replace a logo, upload a new file over the same name. To remove one,
delete the file. Wrong-slug files are silently unused — if a logo doesn't
show, check the spelling against the venue_name in the sheet.

Which venues get logos is a curation (and sales-tier) choice made in this
folder — the build never requires them.
